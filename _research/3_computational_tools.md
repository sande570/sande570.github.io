As a linguistic fieldworker, the lack of technologically advanced language documentation tools is quite apparent to me. I am working to fill this gap by creating online database structures useful for my own work, but also available to other linguists. For example, I co-developed an application with a software engineer, a novel online, searchable, data-entry site called <a href="https://twisted-tongues-beta.appspot.com/#/">TwistedTongues</a>, which I use to maintain the Guébie (Kru) corpus, and as a database tool in Field Methods courses. TwistedTongues is available for use to anyone, and <a href="https://www.twisted-tongues.com/">a manual is available here</a>. I have also created a readable, searchable, publicly available <a href="https://linguistics.berkeley.edu/moro/#/">database of Moro</a> (Kordofanian), which is used by community members and linguists alike. The Moro database code is available on GitHub.
