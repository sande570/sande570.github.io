# Quick Start: Update Profile Picture from Mobile

## 📱 Easiest Method: GitHub Mobile App

### Step 1: Install GitHub App
- **iPhone**: [Download from App Store](https://apps.apple.com/app/github/id1477376905)
- **Android**: [Download from Google Play](https://play.google.com/store/apps/details?id=com.github.android)

### Step 2: Upload Your Photo
1. Open GitHub app and sign in
2. Go to: **sande570/sande570.github.io**
3. Navigate: `assets` → `img`
4. Tap **"+"** button → **"Upload files"**
5. Select your new headshot photo
6. **Important**: Name it `prof_pic.jpg`
7. Tap **"Commit changes"**

### Step 3: Wait & View
- Wait 2-5 minutes for the site to rebuild
- Visit: https://sande570.github.io
- Your new picture will appear!

---

## 🌐 Alternative: Mobile Browser

1. Open browser and go to: https://github.com/sande570/sande570.github.io
2. Sign in to GitHub
3. Navigate: `assets` → `img`
4. Tap **"Add file"** → **"Upload files"**
5. Select your photo and name it `prof_pic.jpg`
6. Tap **"Commit changes"**

---

## ✅ What You Need to Know

- **File Name**: Must be named `prof_pic.jpg` (lowercase, exact spelling)
- **File Location**: Goes in `assets/img/` folder
- **Rebuild Time**: 2-5 minutes for changes to appear
- **Image Type**: JPG, JPEG, or PNG work (JPG recommended)
- **Image Size**: Any size works, but square images (e.g., 500x500px) look best

---

## 🔍 Where the Profile Picture is Used

Your profile picture appears on:
- Homepage (https://sande570.github.io)
- Configured in: `_pages/about.md` (line 9)

---

## ❓ Troubleshooting

**Image not showing?**
- Clear your browser cache or use incognito/private mode
- Make sure the filename is exactly `prof_pic.jpg`
- Wait a few more minutes for the site to rebuild
